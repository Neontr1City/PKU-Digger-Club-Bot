# 自动提名处理标准

规则版本：`2026-09-27.1`。用户于 2026-09-27 确认：以无需管理员参与为默认；单个平台链接缺失直接接受，不通知管理员。这里区分已实现流程、判断规则和外部能力边界。

## 实际流程

1. **接收**：保存提名时，将原始艺人／曲名、两首一组的关系与顺序保留在 SQLite，同时创建唯一处理任务。昵称和备注不发送给曲库。
2. **规范比较键**：解码 HTML 实体、整理空白、Unicode 归一化。比较时忽略大小写、标点和变音符差异；展示文字采用来源中的原文，不使用程序 title-case，也不让语言模型凭记忆改名。
3. **检索候选**：查询网易云网页目录、Apple 中国区 iTunes 目录与 MusicBrainz。必要时使用 MusicBrainz 模糊词项查询恢复轻微拼写错误；用找到的名称继续查询 Apple 美区和网易云曲名搜索。候选仍须通过原始艺人和曲名检查，不能因扩大搜索范围而换成翻唱。
4. **识别录音**：检查艺人身份、曲名和版本；比较跨平台时长，避免把现场／混音／重录接到普通录音上。仅接受检索实际返回的歌曲 ID 与链接。网易云候选另读歌曲详情，确认 ID、名称、时长和封面。
5. **选发行**：优先 MusicBrainz 正式发行的 Album／EP 且无 Live／Compilation 等附加类型；其次优先跨平台专辑名一致的发行，再优先 Apple 发行信息及早期日期。标题带有 greatest／best of／collection／compilation 等的合集降低优先级。无法证实最早正式专辑时保留平台发行与说明，不冒称已核定首版，也不因此打扰管理员。
6. **确定封面**：封面与所选发行绑定，实际下载确认图片可用并缓存；下载失败尝试另一个已匹配发行的封面。没有可用封面时使用明确标注的缺失占位，仍可入队。
7. **保存并入队**：两首都有可信匹配且至少各有一个听歌链接，即自动设为就绪。保存显示名称、专辑、平台原始名称／时长／ID／地区、采用来源、查询记录、修正对照、时间与规则版本。原始提名不改写。
8. **异常处理**：找不到可信歌曲、同名身份无法区分、近似候选相互冲突、两侧实际同曲，或备注存在不能确定对应录音的版本要求时保留待处理。外部源暂不可用导致无法完成时，15 分钟后重试，最多 3 次；可由管理员重新查找。单个平台或封面缺失属于接受状态，不进入异常队列。

自动补全与自动排期是两回事：补全只把提名准备好，不创建当天投票，不发送微信。队首无法处理时继续遵守原有顺序，不擅自跳过。

## 匹配规则的具体含义

- 艺人、曲名分别采用归一化字符串相似度；单次替换、插入、删除及相邻字符交换可作为常见 typo 处理，短于四个字符不启用这一宽松规则。
- 候选的艺人与曲名分数均须 ≥ 0.84，平均 ≥ 0.91；离最高分 0.035 以内的候选如果指向不同艺人／曲名，则视为不能确定。**这些分数是启发式规则，不是正确率或概率。**
- 同一平台、相同艺人名称若对应不同艺人 ID，不自动合并。
- Remastered／Remaster 和对应重制年份可互换、展示时省略；原始返回仍留在证据里。现场、混音、Demo、原声、伴奏、重录、Take、Radio Edit、Mono／Stereo 不按重制版规则抹去。未识别的括号内容保留。
- 同一录音的跨平台连接要求归一化艺人、曲名一致、版本兼容，并且都有时长；允许差值为 `max(4 秒, 较短时长的 2%)`。这不是同一母带的证明。无法满足时仅保留优先发行的一个可信链接。
- 封面只使用对应发行返回的 CDN 地址；平台原始名称、专辑名和封面来源可在后台查阅。无法从来源证实的字段留空或标注未核实。
- 有特殊版本要求时，最好写在曲名中，例如 `Song (Live at …)`。备注中的版本要求不能静默忽略，无法判断时保留待处理。

## 缺失与地区处理

| 情况 | 默认动作 | 是否需要管理员 |
| --- | --- | --- |
| 两个平台均找到且录音兼容 | 保存双链接并入队 | 否 |
| 只找到网易云或 Apple Music | 保存该链接，另一平台显示暂未找到 | 否 |
| 两个平台候选录音冲突 | 保留可信度更高的发行链接，记录另一链接缺失原因 | 否，前提是歌曲身份确定 |
| 没有可用封面 | 显示封面暂缺，继续入队 | 否 |
| 暂无独立来源证明首版专辑 | 使用平台发行及封面，记录未交叉验证 | 否 |
| Apple 中国区搜索无结果，美区有结果 | 保留已找到的美区链接，公共页面标注美区 | 否 |
| 歌曲身份无法确定，或两个平台都没有可信歌曲链接 | 保留待处理及候选 | 是；先尝试自动重试可恢复的查询错误 |

公开可访问的元数据和链接不代表用户在所有地区／账号下都能完整播放。地区不凭 URL 字符串替换伪造，缺失歌曲 ID 不凭经验编造。

## 程序与操作入口

| 文件／入口 | 职责 |
| --- | --- |
| `cricket/music.py` | 三个曲库适配器、请求间隔、1 小时查询缓存、歌曲详情 |
| `cricket/matching.py` | 比较键、typo、版本、同录音及发行优先级规则 |
| `cricket/enrichment.py` | 多源查询、证据、选择策略、入队与失败重试 |
| `cricket/artwork.py` | 有来源约束的封面下载／缓存 |
| `enrichment_jobs` 表 | 独立任务状态，不修改原有已排期快照 |
| 管理后台 → 提名详情 | 状态、修正对照、封面、链接、候选及采用原因；必要时重新查找或人工修正 |
| `uv run python -m cricket resolve` | 处理一组待处理提名后退出，适合验证 |
| `uv run python -m cricket worker` | 每分钟处理一组，同时执行已启用的日常结算与排期 |

仅启动网页不会执行任务。部署时网页和 worker 指向同一数据库、OUTPUT_DIR；保留一个 worker 即可。Docker Compose 的 `schedule` profile 已包含 worker。自动排期关闭时，worker 仍处理提名。

重复提交不会创建重复任务；已就绪、已跳过、已排期内容不被后台改写。任务执行中管理员修改／跳过的结果优先；进程中断超过 15 分钟可重新领取任务。人工重新查询只针对待处理项。旧数据库中原有待确认条目不批量重写，可在详情页点击自动查找。

## 外部能力与来源（2026-09-27 查证）

- [Apple iTunes Search API 官方文档](https://performance-partners.apple.com/search-api)：无需开发者 Token 的目录搜索，包含曲名、艺人、专辑、时长和图片字段，支持地区参数。按官方约 20 次／分钟说明，本实现间隔至少 3.1 秒并缓存；iTunes 搜索不是完整 Apple Music 目录。中国区空结果不能证明 Apple Music 没有此曲。
- [MusicBrainz API](https://musicbrainz.org/doc/MusicBrainz_API) 与 [搜索字段](https://musicbrainz.org/doc/MusicBrainz_API/Search)：录音、艺人身份和发行类型用于交叉核验；本实现请求间隔至少 1.1 秒。社区数据库也可能缺项或出错，不是发行商认证。
- 网易云直接读取其域名下的 [网页搜索](https://music.163.com/api/search/get?s=April&type=1&limit=5) 与 [示例歌曲详情](https://music.163.com/api/song/detail/?ids=%5B4021290%5D)。本机实际返回 JSON，含歌曲 ID、艺人、专辑、时长及封面。**没有找到可保证这一接口长期受支持的官方开发文档**；不使用第三方代理、不登录、不下载音频。限频或接口变化时记录失败并回退。
- [Cover Art Archive API](https://musicbrainz.org/doc/Cover_Art_Archive/API) 是发行封面的后续候选渠道，本版尚未接入。艺人／厂牌官网、Bandcamp、Discogs 是罕见未匹配项的补证来源，目前未实现这些网站的自动抓取，不把它们计入自动覆盖率。

隔离数据库提交两组、四首公开歌曲，使用虚构昵称，未接触真实群：

| 原始输入 | 实际自动输出 | 结果 |
| --- | --- | --- |
| Deep Purpel — Aprli | Deep Purple — April / Deep Purple | 网易云与封面找到；Apple 本次未查到，照常自动入队 |

| The Smiths — There Is a Light That Never Goes Out | 同名歌曲 / The Queen Is Dead | 双平台与封面找到；Apple 美区 |

任务报告保存在忽略目录 `output/enrichment-verification/`，包含请求时间与实际候选。四首样本通过不能推断所有冷门作品的成功率；后续根据真实未匹配样本修订规则并增加回归用例，不靠降低身份或版本检查来追求通过率。
