## 设备与「机器人账号」的含义

本节保留设备路线解释；按 D006，本地电脑和闲置电脑已不作为当前部署选择，后续优先云端。

用户已明确希望机器人以独立账号作为群成员存在。针对现有普通微信群，可研究「单独普通微信账号＋自动化程序」；账号独立不意味着必须配独立电脑，具体设备由接入方式决定。不再默认用管理员日常账号代发。

2026-09-27 补查发现微信团队维护的 ClawBot／OpenClaw 微信通道，但 OpenClaw 当前文档说明其能力声明仅包含私聊及媒体，未声明群聊支持。因此不能把「有官方个人微信机器人通道」等同于「可把官方机器人拉进本群并定时广播」。来源与边界见 research.md 第 6 节。

| 运行方式 | 需要什么 | 能否自动准时发消息 |
| --- | --- | --- |
| 当前日常电脑 | 到点开机联网、登录微信、处于自动化可操作状态 | 条件满足时可尝试；操作期间可能占用前台／鼠标／剪贴板 |
| 专用或闲置电脑 | 同上，但不与日常使用争抢界面 | 运行条件更容易保持，仍需验证登录、锁屏和客户端版本 |
| 云 Windows 桌面 | 云设备、正常登录微信、可用交互桌面 | 可能有租用费用，断开远程桌面后是否可操作待验证 |
| 普通 Linux 云主机＋第三方协议 | 可用的个人微信协议适配器／服务 | 未核实到适合本项目的免费方案，不能保证省设备又免费 |
| 人工转发 | 任意能生成文案／图片的设备，管理员手机发送 | 不需要桌面微信常驻，但用户目前把此项定为后备 |

本活动若不监听群聊，设备原则上只需在每日任务及维护时可用，不要求全天运行。关机、休眠或自动化无法操作时不能准时发送；不擅自修改用户的锁屏／休眠安全设置。手机和电脑同时登录、账号退出等具体行为需按所选客户端实测。

自建网站部署到云端，用户电脑关机不影响群友投票。投票接口按服务器时间检查截止时刻，不依赖每日任务恰好准点运行才拒绝过期票。公开的是提名／投票网页，管理员及微信控制接口需要访问保护。
